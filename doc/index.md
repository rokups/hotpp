S++ is a scripting language for C++ programs. A script is a `.spp` file that looks like C#.
The `sppc` tool turns a script into C++. The engine reloads a changed script while it runs.

- [Getting started](getting-started.html): write a class, check it and compile it.
- [Types](types.html): builtin types, handles, `ref` and `out`.
- [Classes](classes.html): fields, methods, constructors, properties, structs.
- [Inheritance](inheritance.html): native bases, virtual methods, script parents.
- [Module level](module-level.html): `using`, enums, structs, module variables, native stubs.
- [Statements](statements.html): control flow, `try`, string interpolation, casts, `is` and `as`.
